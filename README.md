# Simple Task Manager — AI-Assisted Engineering Workshop Demo

A tiny Task Manager web app, built to demonstrate an AI-assisted workflow
end-to-end: user story → app → manual test cases → automated tests → CI
pipeline → test reports.

## What's in this repo

| Path | What it is |
|---|---|
| `index.html`, `style.css`, `script.js` | The app itself — plain HTML/CSS/vanilla JS, no framework, no backend. |
| `UserStory.docx` | The source user story (US-001) and its 5 acceptance criteria. |
| `TestCases.md` | 6 manual test cases (TC01–TC06) derived from the acceptance criteria. |
| `tests/task-manager.spec.ts` | Playwright automation of those same 6 test cases, mapped 1:1. |
| `playwright.config.ts` | Playwright config — auto-serves the app on `http://127.0.0.1:5500` and runs tests against it. |
| `scripts/generate-summary-report.js` | Builds a plain static pass/fail HTML report from the test run (see "Reports" below). |
| `Jenkinsfile` | CI pipeline: checkout → install deps → install Chromium → run tests → archive reports. |
| `PromptHistory.md` | The prompts used to build this project, step by step. |

## Running the app

No build step — just open it as a static site, either:

- **VS Code Live Server:** right-click `index.html` → "Open with Live Server".
- **Any static server**, e.g.:
  ```
  npx http-server -p 5500 -c-1 .
  ```
  then open `http://localhost:5500`.

## Running the tests

```
npm install
npx playwright install chromium   # first time only
npm test
```

This spins up a local static server on port 5500 automatically, runs all 6
tests headlessly against it, and shuts the server down when done.

## Reports

Two HTML reports are produced per run, both under `test-results/` /
`playwright-report/`:

- **`playwright-report/index.html`** — Playwright's full interactive report
  (timeline, screenshots, traces). **Must be viewed via a server**
  (`npx playwright show-report`) — opening it directly with a double-click
  shows a blank page, because it's a JS-module SPA that browsers block from
  loading over `file://`.
- **`test-results/summary.html`** — a plain static pass/fail summary table,
  generated by `npm run report:summary`. This one opens fine with a plain
  double-click.

## CI (Jenkins)

The `Jenkinsfile` defines a pipeline (`Checkout` → `Install Dependencies` →
`Install Playwright Chromium` → `Run Playwright Tests`) that runs all 6
tests on every build, fails automatically if any test fails, and archives
both `playwright-report/**` and `test-results/summary.html` as build
artifacts regardless of outcome.

## Project scope

This is intentionally minimal — a workshop demo, not production software.
Out of scope by design: login/auth, a database/API, task persistence,
search/filter/sort, and cross-browser/responsive/accessibility/performance
testing. See `UserStory.docx` and `TestCases.md` for the exact boundaries.
